# Use with JMRI

## Create a Loconet connection
- choose the "LocoBuffer-USB" connection type
- select the USB port ofthe Arduino
- choose the "Stand-alone LocoNet" command station
- check the baud rate and change `JMRI_LNET_BAUD` in the file `leader.ino` to match
