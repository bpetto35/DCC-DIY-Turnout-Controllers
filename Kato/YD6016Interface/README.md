# Interface to provide DCC signal to YD6016LNCS

## Goals
- chain in DCC bus
- provide DCC wire A to YD6016LNCS Common
- provide DCC wire B to rail
- accept 4 occupencies detection signals from YD6016LNCS
- route occupency to each rail
